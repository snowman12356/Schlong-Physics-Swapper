# SPS SOFTBODY combined genital XML (natural hang)

This optional compatibility component is for GT SOFTBODY 3.37.2 together with
a compatible SOS, TNG or UBE six-bone genital mesh using
`NPC Genitals01 [Gen01]` through `NPC Genitals06 [Gen06]`.

It is the SPS author's own preset. It uses the same combined normal, soft and
anal SOFTBODY collision profiles as "SOFTBODY SPS", with the physics tuned for a
heavier, more natural hang:

- More gravity on the shaft and balls (shaft 0.54 to 0.75, balls 0.90 to 0.95).
- The shaft base (Gen01) rests closer to the balls, and the rest of the shaft
  (Gen02 to Gen06) has more room to curve downwards.
- The balls have wider and softer joints, so they move more and still hang
  correctly when the character bends over.

It was tuned for one large mesh. Check it on your own mesh: on a smaller mesh the
shaft may sit too close to the balls and clip. If it does, choose "Use my SOFTBODY
physics" instead.

Select this component only when SOFTBODY and a matching six-bone genital mesh are
installed, and choose it instead of the other SOFTBODY options, not in addition.
The SPS mod must win conflicts for `MaleGenitals.xml`, `MaleGenitalsSoft.xml`
and `MaleGenitalsToAnus.xml`. In MO2, place SPS below SOFTBODY and other mods that
provide those files. After installing, restart Skyrim or use SPS Repair current
physics once so FSMP reloads the active profile.

SOFTBODY: <https://www.nexusmods.com/skyrimspecialedition/mods/152103>

SOFTBODY's Nexus permissions allow modified releases and asset reuse with
credit to the original creator. Its author note prohibits commercial use and
inclusion in directly or indirectly paid compilations. This compatibility
component must remain free.
