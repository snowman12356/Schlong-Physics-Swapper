# SPS author's personal physics

This optional `MaleGenitals.xml` is the SPS author's generally tuned physics
profile for compatible SOS, TNG and UBE genital meshes using
`NPC Genitals01 [Gen01]` through `NPC Genitals06 [Gen06]`.

It provides full six-bone SMP shaft dynamics, scrotum dynamics and a compatible
`MaleGenitals` collision shape. It does not contain SOFTBODY's expanded normal,
soft or anal collision profiles. Users of GT SOFTBODY 3.37.2 should select the
separate SPS SOFTBODY physics option instead.

The SPS mod must win conflicts for `MaleGenitals.xml`. In MO2, place SPS below
other mods that provide the same file.
