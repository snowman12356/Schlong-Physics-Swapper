# SPS SOFTBODY combined genital XML

This optional compatibility component is for GT SOFTBODY 3.37.2 together with
a compatible SOS, TNG or UBE six-bone genital mesh using
`NPC Genitals01 [Gen01]` through `NPC Genitals06 [Gen06]`.

The three XML profiles combine the SPS author's compatible shaft dynamics
and collision exclusions with Goutou's SOFTBODY normal, soft and anal collision
profiles. Each file contains exactly one `MaleGenitals` shape: the merged shape
retains SOFTBODY's weight thresholds and adds the SPS compatibility exclusions.

Select this component only when SOFTBODY and a matching six-bone genital mesh
are installed. The SPS mod must win conflicts for `MaleGenitals.xml`,
`MaleGenitalsSoft.xml` and `MaleGenitalsToAnus.xml`. In MO2, place SPS below
SOFTBODY and other mods that provide those files.

SOFTBODY: <https://www.nexusmods.com/skyrimspecialedition/mods/152103>

SOFTBODY's Nexus permissions allow modified releases and asset reuse with
credit to the original creator. Its author note prohibits commercial use and
inclusion in directly or indirectly paid compilations. This compatibility
component must remain free.
